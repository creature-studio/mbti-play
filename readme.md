# 人格漂移 / Personality Shift

> 别让他们看出你真正想成为什么人。

手机优先的多人轻竞技卡牌 Web 游戏。**不是 MBTI 测试**：秘密目标、生活梗卡牌、互相干扰、限时反制，以及“我不装了”的最终宣言。

## 启动

Node.js 22+，npm。

```bash
npm install
npm run dev             # http://localhost:3000，Vite 中间件 + Socket.IO 同源服务
```

生产运行：

```bash
npm run build           # TypeScript 检查 + Vite 生产构建
npm start               # 0.0.0.0:3000
# PORT=8080 npm start    # 可选端口
```

前端不调用独立 localhost API。静态页面和 Socket.IO 共用一个端口，适用于 HTTPS 反向代理和 Arena Live Preview。正式部署反代需允许 WebSocket Upgrade。

## 马上试玩

- **快速开始**：1 位玩家 + 3 个策略 Bot，不需要登录。
- **创建房间**：2–6 人，可加减 Bot，复制邀请链接给朋友。
- **加入房间**：输入 6 位房间码；每位真人准备后，由房主开始。
- **刷新页面**：使用浏览器本地临时身份自动恢复座位、手牌和秘密目标。
- 同一浏览器标签页共享一个身份。测试多位真人请使用不同浏览器 / 无痕窗口 / 独立浏览器上下文。

## 30 秒规则

1. 开局拿到**秘密的四字母目标**。四条轨道的内部范围为 -3～+3，界面只显示左右倾向。中线不满足任何方向。
2. 每回合自动抽 1 张，可以出 1 张；可以打给自己，也可以给对手“帮倒忙”。当前人格的能力每回合可用一次。
3. 四条轨道都到目标侧，点击 **我不装了**。系统验证后，其他人有 16 秒、每人最多 1 张牌来打断。最终仍满足目标则获胜。

额外博弈：

- 手里有反制牌，被攻击时出现 **8 秒回应窗口**。也可以提前打出防护。反制卡牌不抵消人格能力或世界事件。
- **猜人格**花 2 点洞察；猜对抽 2 张，猜错向被猜者泄露自己的一条目标信息。每回合回复 1 点洞察，上限 3。
- 每 2 轮更换一次真实生效的世界事件。
- 伪装牌隐藏轨道 / 伪装公开人格，持续至自己下回合；不会改变真实目标。
- 45 秒回合计时。未出牌直接结束时，额外抽 1 张。
- 手牌上限 8；新牌进手时若已满，自动弃掉最左边的旧牌。手牌始终流动，避免坏牌僵局。
- 没对齐就宣言：弃 1 张、洞察清零、结束回合。被成功打断：洞察清零、结束回合。
- **第 9 轮起人格加速**：每次回合开始，最远离目标的一条轴自动朝目标移动 1 格，帮助对局收束。
- 轨道处于中线时，能力按左侧字母计算；界面当前人格会显示 `·`，避免错误地表示目标已满足。

## 已实现

- 首页、创建 / 加入房间、准备、秘密人格翻牌、游戏桌、猜测与秘密笔记、反制、宣言、结算、再来一局。
- **54 张不同卡牌**：20 人格、10 攻击、8 防御、8 策略、8 特殊。卡牌可重复出现；牌库是三套卡，共 162 张。
- **16 种不同、实际生效的人格能力**，随当前人格自动改变。
- **10 个世界事件**，实际修改漂移或触发全员效果。
- 确定性纯引擎；服务器唯一决定合法性、目标验证和胜负。
- Bot 评估自己的目标收益、观察公开轨道威胁、选择能力、保护 / 反弹、下注猜测、偶尔伪装、拦截宣言。正常行动不读取对手隐藏目标。
- 玩家刷新、30 秒短线宽限、Bot 接管、重连归还、离开与房主转移。
- 响应式扇形手牌、按压 / 弹簧 / 拖放、点击目标替代拖拽、键盘选牌、左右翻牌按钮。
- 定向飞牌、命中光环 / 粒子、轨道滑动、人格漂移提示、宣言高潮、结算纸屑。
- 20 种分层合成音效（默认关，无背景音乐）：选牌、抽牌、洗牌、翻牌、甩牌、命中、护盾、反弹、漂移、能力、回合、反制提醒、最后 3 秒倒计时、世界事件、猜中、失误、宣言及胜负结尾等。
- 顶部扬声器一键静音，旁边「音效设置」可调音量、试听 8 种核心音效；偏好保存在本地。手势解锁音频、后台停声、立即静音、限流与压限保护；不补播后台和重连时错过的声音。受支持设备另有轻震动。
- 本地字体、本地 SVG 卡牌插画、约 69 KB 的优化 WebP 主视觉；不依赖 Google Fonts / 图片 CDN。
- 减少动态效果偏好、弹窗焦点管理、手机安全区。
- 结算展示胜者、所有秘密目标、个人变化路线、多种趣味奖项、原生分享 / 复制战报。

## 架构

```text
shared/
  types.ts               玩家、房间视图、状态机、动作、卡牌类型
  cards.ts               54 张卡 + 10 个世界事件；统一数据结构
  personalities.ts       16 种能力文案、人格 / 目标计算
  player.ts              玩家初始状态
  runtime.ts             确定性 PRNG、洗牌、抽牌、轨道变化、日志
  effects.ts             数据驱动卡牌效果解析与应用
  engine.ts              状态机、动作验证、能力、宣言 / 反制、视图脱敏
  bot.ts                 策略搜索与公开信息启发式
server/
  index.ts               Socket.IO 权威房间、临时身份、计时、重连、Bot 调度
src/
  App.tsx                页面路由、首页弹窗、个人偏好
  hooks/useGame.ts       同源 Socket.IO 连接和事件绑定
  hooks/useSound.ts      声音偏好、手势解锁、静音和音量控制
  hooks/useGameAudio.ts  服务端状态转场与本地倒计时音效
  audio/cues.ts          声音配方（音高、包络、噪声、时序）
  audio/AudioEngine.ts   单 Web Audio 图、压限、节点回收、后台停声
  audio/gameCues.ts      可测试的状态转场 → 音效映射
  components/
    Home / Lobby / GameTable / Results
    Card / Artwork / Hand / Axes / Avatar
    GameEffects / Declaration
    Modal / Rules
  styles.css             响应式视觉系统和低动态偏好
```

`reduceGame(state, action, now)` 不读系统时钟、不使用 `Math.random()`、不修改传入状态。服务器传入时间；牌序来自可复现 PRNG。相同状态、动作和时间有相同结果。

新增现有效果类型的卡牌只需修改 `shared/cards.ts`；新机制加到 `Effect` 联合类型及 `effects.ts`。能力动作与卡牌动作分离。

### 隐私与授权

服务器为每个连接构造专属 `ViewState`，不会下发对手目标、手牌、线索、隐藏轨道、私有人格历史或牌库。宣言和结算按规则公开目标。

临时重连凭据仅存本地浏览器。公开玩家 ID 是凭据的单向摘要，**不是重连凭据本身**。服务器忽略客户端提供的 `playerId`，只以连接身份执行动作。含基本操作限流、消息大小限制、6 人容量限制和随机房间码。

## MVP 边界

- **房间在单进程内存中**。服务器重启、重新部署会清空房间；静置 2 小时的房间回收。不是持久化游戏服务器，暂不支持多实例 / 跨区匹配。
- 邀请进入房间仅限大厅阶段。游戏中主动离开会交给 Bot，不开放中途回座；短暂掉线则支持恢复原位。
- 无账号、登录、商城、付费或全服排行榜；分享的是文本战报，不是云端永久战报页。
- 动效是轻量浏览器实现，不依赖 WebGL；卡牌插画复用主题图形体系，主视觉使用生成插画。
- 5–10 分钟是调节目标，实际时长受人数和思考速度影响。第 9 轮加速规则用于防止僵局。真实用户留存、长期平衡和低端手机实机帧率仍需后续测试，不能由自动化模拟代替。

字体许可证随 Fontsource 包保留。人格设定仅供娱乐，不构成心理测评或人格诊断。
